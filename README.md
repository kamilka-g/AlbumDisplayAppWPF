# 🎵 Music Album Viewer - WPF App

A simple WPF application for browsing music albums stored in a text file. The app allows you to switch between albums, view details like artist name, album title, release year, and download count — and simulate downloads.

## 🚀 Features

- Navigation through music albums (next/previous)
- View artist, title, song count, release year, and downloads
- Download button increases download count
- Data loaded from a `.txt` file
- Custom UI using WPF and images


## 🧾 Example Format of `Data.txt`

Each album is represented by 5 lines:
Artist Name 
Album Title
Number of Songs 
Release Year 
Download Count


## 🛠 Built With

- C#
- WPF (Windows Presentation Foundation)
- .NET Framework


## 🔧 Run the App

1. Open the solution in Visual Studio
2. Make sure `Data.txt` is in the output directory
3. Run the project
